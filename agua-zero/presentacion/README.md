# Presentación AGUA ZERO™

Pitch en HTML con el look de la tienda. Abre `index.html` en Chrome y presiona **F** para pantalla completa.

## Dónde subirla

Súbela **dentro de `agua-zero/`** en el repo `mm-ctrl-mx/aguazero`:

```
agua-zero/
  index.html          ← la tienda
  img/
  visitas/
  presentacion/       ← esta carpeta
    index.html
    img/
    musica/
```

Así queda publicada en **https://aguazero.lol/presentacion/** y la diapositiva «Tienda en vivo» carga la tienda de al lado. La página pide no ser indexada por buscadores, pero cualquiera con el enlace puede verla.

Si la carpeta queda en otro lugar, la tienda en vivo se busca en `../agua-zero/` y, si no está, se carga desde https://aguazero.lol.

## Controles

| Tecla | Acción |
|---|---|
| → · espacio · clic | Avanzar (los datos aparecen uno por uno) |
| ← | Regresar |
| I | Índice de diapositivas |
| M | Música on/off |
| F | Pantalla completa |
| Inicio / Fin | Primera / última |

El primer clic o → activa la música: el navegador no deja reproducir audio antes.

## Música

- `musica/2aguazweimp3.mp3` suena cuando aparece el logo (diapositiva 2) y termina aunque se avance.
- `musica/cumbia2mp3.mp3` suena en bucle en la diapositiva final.
