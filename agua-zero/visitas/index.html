Acceso del equipo

Este panel lee las estadísticas de GoatCounter. Pega un token de solo lectura; se guarda en este navegador.

  1. Entra a multimediacaav.goatcounter.com.
  2. Ve a Settings → API (o tu usuario → API) y crea un token nuevo.
  3. Marca solo el permiso Read statistics y copia el token.

Ese token no funcionó: revisa que tenga el permiso «Read statistics».

Para compartir con el equipo puedes mandar el enlace aguazero.lol/visitas/#token=TU_TOKEN: la parte después de # no viaja al servidor y la página la borra de la barra al leerla.
